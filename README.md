# эмено

Visual grammar for Sanskrit sandhi, rendered as chalk-cube animations.

**→ [Смотреть демо](https://vimo17.github.io/emeneau/)**

---

## Что это

Учебное приложение для изучения санскритской сандхи по «Sanskrit Sandhi and
Exercises» М. Б. Эмено, Б. А. ван Нотена (2-е перераб. изд., 1968) —
сборнику практических правил и упражнений на внешнее и внутреннее сандхи.

Два независимых способа показать правило:
- **2D-подсветка алфавита** (источник/триггер/результат прямо на алфавитной
  панели) — покрывает 64 из 71 правила.
- **3D-анимация** («слот-движок»: кубики мела, WebGL/Three.js — падают,
  сближаются, превращаются, исчезают) — пока 3 правила из 71 (agnayas,
  āsīt, śādhi), плюс два готовых, но не подключённых к приложению
  тестовых полигона (taddhiraṇyam, vāk asti).

## Структура

```
docs/                                ← публикуется через GitHub Pages
├── index.html                       ← landing-страница со ссылками на всё
├── app/
│   ├── sanskrit-sandhi-app.html     ← основное приложение (все 71 правило)
│   ├── data.js                      ← декларативные данные (тексты, роли, упражнения)
│   ├── alpha-panel.js               ← правая панель: алфавит, тултип, аудио-заглушка
│   ├── rule-panel.js                ← левая панель + центр: карточки правил, показ выбранного
│   ├── role-demo.js                 ← 2D-подсветка источник/триггер/результат
│   ├── lib/                         ← 3D слот-движок (7 модулей, барабан-файл slot-engine.js)
│   ├── examples/                    ← данные конкретных 3D-примеров (rule3, rule7, rule15, ...)
│   ├── vendor/three.module.js       ← Three.js r128, вендорено локально (без CDN, без сборки)
│   └── test-slot-engine*.html       ← изолированные тестовые полигоны для 3D-примеров
├── effects/                         ← более ранние, самостоятельные прототипы-этюды
│   └── ...                          ← (гуна/вриддхи/ассимиляция/ослабление — не на слот-движке)
└── reference/                       ← сканы источника и лингвистический разбор (не в git)
```

Основное приложение и 3D-примеры используют общий слот-движок и не требуют
сборки — открываются прямо в браузере (ES-модули). `docs/effects/*.html` —
более старые самостоятельные этюды, каждый сам себе Three.js-сетап;
полезны как референс техник, но архитектурно не связаны со слот-движком.

## Разработка

```bash
npm install         # тесты используют three как dev-зависимость (см. tests/README.md)
npm test            # 132 теста, встроенный тестраннер Node, без Jest/Vitest
npm run lint        # ESLint, только "рекомендованные" правила
npm run check-conventions   # автоматическая проверка, что в docs/app не завелись
                            # комментарии с историей рабочих сессий («заход N»)
npm run audit               # известные уязвимости в зависимостях (--audit-level=high)
```

Всё это же гоняется в CI (`.github/workflows/ci.yml`) на каждый push/PR.
