# эмено

Visual grammar for Sanskrit sandhi, rendered as chalk-cube animations.

**→ [Смотреть демо](https://vimo17.github.io/emeno/)** *(появится после включения GitHub Pages, см. ниже)*

---

## Что это

Учебное приложение для изучения санскритской сандхи по «Sanskrit Sandhi and Exercises» М. Б. Эмено (1958) — сборнику практических правил и упражнений на внешнее и внутреннее сандхи. Кубики мела в WebGL/Three.js визуализируют, что физически происходит со звуком в каждом правиле: усиливается, ослабляется, ассимилируется, выпадает.

## Два основных файла

Всё остальное — вспомогательные наработки вокруг этих двух:

- **[`app/sanskrit-sandhi-app.html`](docs/app/sanskrit-sandhi-app.html)** — основной тренажёр (v19): 71 правило сандхи, алфавитная панель, таблица гуна/вриддхи. Зона анимации пока пуста — в неё войдут эффекты ниже, после доводки.
- **[`effects/rule-guna-agnayas.html`](docs/effects/rule-guna-agnayas.html)** — первый полный сценарий эффекта: `agni- + as → agnayas`. Это образец, по которому проверялась вся логика (дальнодействие → гунирование → замена на a+y с параллельным показом «было/стало»), и только после него имеет смысл делать остальные эффекты.

## План работы и статус

Рабочий процесс сознательно последовательный: **сначала довести один пример до конца целиком** (проверить всю логику на конкретном слове), **затем зафиксировать эффект в общем перечне**, и только после этого переходить к следующему — а не разрабатывать все эффекты параллельно набросками.

| Эффект | Статус |
|---|---|
| Гуна (गुण) — `agni-` + `as` → `agnayas` | ✅ готово |
| Вриддхи (वृद्धि) — `u` → `au` | ⚠️ логика готова, **цвета требуют доработки** |
| Ослабление / сампрасарана (सम्प्रसारण) — `ya` → `i` | ⚠️ логика готова, **цвета требуют доработки** |
| Ассимиляция по звонкости (आदेश) — `t` → `d` | 🔶 почти готово (осталось свечение влияющей буквы) |
| Ассимиляция по месту образования | ⏳ запланировано |
| Висарга | ⏳ запланировано |
| Дальняя ретрофлексия (n → ṇ от r/ṣ) | ⏳ запланировано |
| Выпадение (लोप) | ⏳ запланировано |
| Удвоение / редупликация (द्वित्व) | ⏳ запланировано |
| Аугмент (आगम) | ⏳ запланировано |
| Удлинение (दीर्घ) | ⏳ запланировано |

Полное описание каждого эффекта и соответствующие правила Эмено — в [`effects-map.html`](docs/effects/effects-map.html); этот же файл и есть план работы в развёрнутом виде.

## Технически

- Three.js r128, без сборщика — импорт по `importmap` с cdnjs.
- Процедурная генерация меловой текстуры (шум, фаски, зерно) — единый пайплайн, общий для всех демонстраций.
- Цвет кодирует ступень гласного (насыщение при усилении, обесцвечивание при ослаблении), тип движения — тип операции над сегментом (подробнее в карте эффектов).
