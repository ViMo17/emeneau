Диагностика асимметричной прозрачности (CLAUDE.md, Часть 6, п.0) — контролируемый эксперимент: одна и та же буква "k" (единый цвет) на ВСЕХ 10 слотах, единственная переменная — позиция. У каждого кубика ЗАДНЯЯ грань (idx5, обычно не видна камере напрямую) держит полную непрозрачность (opacity=1), у остальных пяти (idx0-4, включая нижнюю) — 40% (opacity=0.4). Статичная сцена, без анимации/падения — сразу в покое. Не часть движка приложения, только для скриншота+сравнения по слотам. Открывать через живой сайт (https://).
