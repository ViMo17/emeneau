Слот-движок — правило 10, вариант А (полное соответствие Эменó, решение 2026-10-13). gam- «идти» → наст. основа gach- (грамм. факт, не сандхи) + -ati → gacchati «он идёт». Эменó, с. 21: «В положении после гласной ch заменяется на cch (W 227)». ОДИН шаг: корневой a (условие — только предшествующая гласная) пульсирует к ch; ch отпочковывает клона (`bud`) влево сразу с буквой c — удвоенный придыхательный записывается приставлением непридыхательного (Whitney §154).
