Слот-движок — правило 10, ПЕРВЫЙ реальный тест гэпа DOUBLE с деаспирацией. gam- «идти» → наст. основа gach- (грамм. факт, не сандхи) + ati (тематич. -a- + оконч. 3 sg. -ti) → gacchati «идёт». Whitney §227 (сверено дословно): ch между двух гласных геминирует — cch. Whitney §154 (сверено дословно): при удвоении придыхательного смычного результат — «неприд.+прид.» ОДНИМ актом. ДВА ОТДЕЛЬНЫХ ВИДИМЫХ ШАГА, не один (прямая правка пользователя: «мы должны отделить деаспирацию — каждую итерацию мы показываем пользователю»), той же логикой, что уже применена к правилу 9: (1) Геминация — `bud` (как rule61), клон рождается С ТЕМ ЖЕ глифом 'ch' → «chch» (Уитни сам называет это реальным рукописным вариантом написания, не изобретённая промежуточная стадия). Шаг 1 заканчивается РОВНО в момент завершения bud. МЕЖДУ ШАГАМИ — НАСТОЯЩАЯ ПАУЗА (прямая правка: «мы должны показать паузу после удвоения, перед шагом 2») — 1000мс автоматической паузы-проявления (`_reveal`, встроенный механизм движка, activeSlots шагов разные), «chch» просто стоит на экране. (2) Деаспирация (начинается только ПОСЛЕ паузы) — ЛЕВАЯ копия теряет придыхание: ch→c. НАЙДЕНО: c/ch — пара внутри ОДНОЙ (палатальной) варги, отличаются РОВНО придыханием — это `TRANSFORM_KIND.vargaPair` («придых↔непридых» уже названо одним из её случаев в реестре) — ТА ЖЕ операция, что у cartva/jaśtva, ни одной новой строчки в движке. Причина — исходная (правая) копия пульсирует к клону (короткий, снятый импульс — «замечание соседа», не дальнодействующий сигнал): наличие идентичного соседа и есть условие.
