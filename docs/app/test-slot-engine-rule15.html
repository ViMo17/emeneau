Слот-движок — заход 29, śādhi: теперь настоящая пауза. DH+I подъезжают ВПЛОТНУЮ к S (закрывают только исходный зазор) → явная пауза (контакт установлен, ничего не двигается) → ИМЕННО в этой паузе S исчезает (реакция на контакт, не на движение мимоходом) → DH+I довершают путь на освободившееся место. Новая общая возможность движка: approach умеет двухотрезочный путь с паузой между отрезками (midDistance/midHoldDur/ leg2Dur) — не хак под этот пример, пригодится для любого похожего случая.
