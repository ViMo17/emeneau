Слот-движок — второй пример фазы автоматической постройки по номерам правил. bhava- «быть» (тематическая основа наст. вр., класс I, от bhū-) + -ī- (суффикс оптатива) + -t (окончание 3 л. ед. ч. действ. залога) → bhavet «был бы» (правило 2, Whitney §565a: «ī blends with the final a to e» — ОДИН слитный акт, не предварительная гунация основы, как у agnayas §338a). Части падают ОТДЕЛЬНО (формула даёт их через «+»). a и ī — РАВНОЗНАЧНЫЕ участники eka-ādeśa (тот же приём, что у rule1): два встречных influence, затем ī→e (transform, label:'guṇa'), a поглощается (elide, quiet, label:'ekādeśa', не 'lopa' — результат ЕСТЬ). ОТДЕЛЬНО, ПОСЛЕ — e approach'ем закрывает первый зазор, затем t закрывает второй: bhavet становится единым словом. Данные — examples/rule2-bhavet-slots.js. Открывать через живой сайт (https://).
