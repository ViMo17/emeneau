Слот-движок — третий пример фазы автоматической постройки по номерам правил (после rule1, rule2). strī- «женщина» (основа ж.р. на долгий ī, Whitney Declension III, «nadī»-тип) + ā (окончание Instr. sg. для ī/ū-основ) → striyā «женщиной». Whitney §129/§129a (сверено дословно по Wikisource): §129 — общее правило (i/u/ṛ перед иным гласным → ПРОСТО полугласный, сам гласный теряется, это правило 6); §129a — ИСКЛЮЧЕНИЕ для ОДНОСЛОЖНЫХ основ (strī-, bhū-): вместо потери гласного целиком — ī РАСПАДАЕТСЯ на i (короче, но остаётся) и y (новый, добавочный). Panini 6.4.77 (aci śnudhātubhruvāṃ yvor iyaṅuvaṅau) — та же замена (iyaṅ/uvaṅ) для корня/bhrū; точная сутра для strī конкретно не подтверждена, открытый пункт. Механика — split, ТА ЖЕ геометрия, что в agnayas (одна буква становится двумя, подъём вверх) — здесь БЕЗ предшествующего грамматического шага (ī уже стоит в основе, событие целиком — прямое следствие столкновения с ā). approach (несовместимость двух гласных, отскок) → split (ī уходит в отстойник, i возвращается на своё место, y прилетает в зазор, зарезервированный пустым с самого начала — зеркально Y в agnayas). ā (триггер) физически не сдвигается с места, кроме самого отскока. Подпись пилюли — 'iyaṅ' (Panini, точный термин для i/ī→iy, u/ū→uv), НЕ 'ayādi' (тот термин — за agnayas, другая пара звуков). Данные — examples/rule4-striya-slots.js.
