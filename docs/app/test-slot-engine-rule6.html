Слот-движок — пятый пример фазы автоматической постройки по номерам правил. pitṛ- «отец» (родственный термин, ДВУСЛОЖНАЯ основа на ṛ — в отличие от односложной pṛ- в правиле 5) + os (оконч. Gen./Loc. du.) → pitros «(двух) отцов». Whitney §129 (сверено дословно по Wikisource): ОБЩЕЕ правило — i/u/ṛ перед иным гласным ПОЛНОСТЬЮ становятся полугласным (y/v/r), без остатка гласного (в отличие от W129a, исключения для ОДНОСЛОЖНЫХ основ/корней в правилах 4/5, где гласный распадается на короче+согласный, а не пропадает целиком). Panini 6.1.77 iko yaṇ aci — устоявшийся термин этой замены, yaṇ. Механика — ПОЛНОЦЕННЫЙ transform (1-к-1, не split): ṛ становится r НА МЕСТЕ, без нового кубика. signal:'blank' — не серебро (серебро строго за гунацией, качественно другая операция). Впервые в этой сессии оба соседа цели заняты одновременно (t слева, o справа, раскладка без единого зазора) — боковое раскачивание (clearance) отключено вовсе (clearance:0, пустого места нет ни в одну сторону), выдвижение по Z (clearanceZ:-0.5, та же техника и число, что в правиле 2) спасает от прохождения сквозь текстуру соседей на диагональных углах вращения. Подпись пилюли — 'yaṇ' (не путать с iyaṅ/uvaṅ у правил 4/5 — там исключение с остатком гласного, здесь общее правило без остатка). Данные — examples/rule6-pitros-slots.js.
