Слот-движок — ПЕРВЫЙ реальный тест истинной геминации (буква удваивается САМА СОБОЙ, не превращается в другую — гэп DOUBLE из CLAUDE.md/interaction-registry.md). hasan «смеющийся» + agacchat «шёл» → hasannagacchat «шёл смеясь» (правило 61): после краткого простого гласного конечный назальный n удваивается перед следующим гласным. Оба условия (предшествующий и следующий гласные) влияют на n разом; сама геминация — НОВАЯ операция движка `bud` («отпочкование», зеркало `merge`): источник вспыхивает и остаётся на месте, клон появляется ровно в его позиции и едет по прямой в свой слот с пружинкой на прибытии. Отдельного approach не нужно — целевой слот клона это и есть внешний зазор между словами, он закрывается самим событием. Данные — examples/rule61-hasannagacchat-slots.js.
