Слот-движок — заход 50, первый пример на ДВЕ вещи разом: цепочку из двух rule-шагов подряд (правило 70, потом 71) и сжатый крайний блок для длинного слова. tat + hiraṇyam → taddhiraṇyam: словофинальный t (слот 4) влияет на h (слот 6) — h→dh (правило 70, 360°, нейтральная грань — не парная замена внутри варги, h вне варг вообще); затем уже готовый dh влияет на тот же t — t→d (правило 71, 180°, та же механика, что у vāk asti). Хвост «raṇyam» (6 фонем, не участвует ни в одном шаге) — сжат в один кубик с авто-подгонкой шрифта (заход 48).
